## Website Description
Lens & Light is a personal photography website showcasing my interest in photography, nature, landscapes, wildlife and beautiful scenery. The website allows visitors to learn about my photography interests, explore my portfolio and view my contact information.

## Redesign Summary
The website was redesigned to improve its structure, appearance, usability and responsiveness.

The improvements include:
- Improved HTML5 semantic structure.
- Organised navigation links.
- Updated photography portfolio gallery.
- Improved image descriptions using alt attributes.
- Improved layout and spacing.
- Responsive design for mobile, tablet and desktop screens.
- Added meaningful HTML and CSS comments.

## How to View the Website

1. Download or clone the project repository from GitHub.
2. Open the project folder in Visual Studio Code.
3. Make sure the images folder and CSS folder are included.
4. Open the index.html file.
5. Right-click and select Open with Live Server, if the extension is installed.
6. The website will open in your browser.

You can also open index.html directly in a web browser.

## Responsive Design Approach

The website uses responsive web design techniques to display correctly on different screen sizes.

CSS media queries are used to adjust the layout for mobile phones, tablets and desktop computers.

The design uses:
- Flexbox to organise navigation and content.
- CSS Grid to display the photography gallery.
- Flexible image sizing to prevent images from overflowing.
- Media queries to adjust spacing, font sizes and gallery columns.
- Relative sizing to make the layout adapt to different screens.

The goal is to provide a website that is easy to navigate and read on all devices.

## Git and GitHub

The redesign was developed using a separate GitHub branch rather than making changes directly to the main branch.

The development process included:
1. Creating a new redesign branch.
2. Updating the HTML and CSS files.
3. Adding and organising images.
4. Committing changes using descriptive commit messages.
5. Pushing the branch to GitHub.
6. Creating a Pull Request targeting the main branch.
7. Reviewing and merging the Pull Request.

## Reflection

During this redesign, I improved my website by adding semantic HTML elements, organising my files into separate folders and improving the overall structure of my photography website. I also learned how to use local and externally hosted images and provide alternative text to make images more accessible.

One challenge I faced was organising the website files and making sure the image and CSS paths worked correctly. I also had to consider how the website would appear on different screen sizes. Using CSS media queries, Flexbox and Grid helped me make the website more responsive and easier to use.

Another important thing I learned was how to use Git and GitHub branches. Instead of making changes directly to the main branch, I created a separate redesign branch to work on my improvements. I then committed my changes using meaningful messages and pushed them to GitHub. Finally, I learned how to create a Pull Request, review my changes and merge them into the main branch.

Overall, this assignment helped me improve my HTML and CSS skills while giving me a better understanding of responsive web design and version control.
